# 記憶配對遊戲 (Memory Match Game)

一個有趣的單人益智網絡遊戲，挑戰你的記憶力！

## 🎮 遊戲特色

- **三種主題**：動物 🐾、水果 🍎、符號 ⭐
- **三個難度級別**：
  - 簡單：12 張卡片（6 對）
  - 中等：16 張卡片（8 對）
  - 困難：20 張卡片（10 對）
- **計時器**：追蹤你完成遊戲所需的時間
- **計步器**：記錄你的移動步數
- **精美動畫**：流暢的卡片翻轉效果
- **響應式設計**：適配各種設備

## 🚀 快速開始

### 安裝依賴

```bash
npm install
```

### 開發模式

```bash
npm run dev
```

在瀏覽器中打開 [http://localhost:3000](http://localhost:3000) 查看遊戲。

### 構建生產版本

```bash
npm run build
npm start
```

## 📦 部署到 Vercel

### 方法 1：通過 Vercel CLI

```bash
npm install -g vercel
vercel
```

### 方法 2：通過 Vercel 網站

1. 訪問 [vercel.com](https://vercel.com)
2. 導入你的 Git 倉庫
3. Vercel 會自動檢測 Next.js 項目並進行配置
4. 點擊 "Deploy" 即可

### 方法 3：一鍵部署

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=YOUR_REPO_URL)

## 🎯 如何遊玩

1. 選擇你喜歡的主題（動物、水果或符號）
2. 選擇難度級別（簡單、中等或困難）
3. 點擊卡片翻開並記住位置
4. 找到兩張相同的卡片進行配對
5. 配對所有卡片以完成遊戲
6. 嘗試用最少的步數和最短的時間完成挑戰！
